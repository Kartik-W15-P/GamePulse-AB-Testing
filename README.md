
# GamePulse — Mobile Game A/B Testing

## Overview

GamePulse is a product analytics project that evaluates whether a mobile game update improves player retention.

The project compares two experimental groups:

- Control: gate_30
- Experiment: gate_40

## Business Objective

Determine whether moving the game's progression gate from level 30 to level 40 improves player retention.

## Dataset

Cookie Cats A/B Testing Dataset.

Expected dataset size: approximately 90,000 player records.

## Key Metrics

- Day-1 player retention
- Day-7 player retention
- Game rounds played

## Technologies

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- SciPy and Statsmodels
- JupyterLab
- Streamlit

## Statistical Methods

- Exploratory Data Analysis
- Bootstrap Resampling
- Confidence Intervals
- Hypothesis Testing
